# Location d'habits traditionnels tunisiens

Application web statique permettant de gérer l'ajout et la location d'habits traditionnels tunisiens (HTML5, CSS3, JavaScript).

## Fonctionnalités
- **Ajout d'un habit (`ajout.html`)** : formulaire d'ajout d'une tenue avec contrôle de saisie (`controles.js`).
- **Location d'un habit (`location.html`)** : formulaire d'enregistrement de location avec vérification du code, de la CIN et de la durée.
